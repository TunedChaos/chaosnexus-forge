# Forge test fixtures (Scripts)

Dev-only Rhai plugins used by ChaosNexus Forge unit/E2E canvas tests.

These are **not** published in the ChaosNexus Scripts polyrepo or the Suite installer.
The public Scripts tree ships a single example plugin (`translation_test`).

## Layout

- `plugins/terminal/` - multi-lane AST / canvas parity fixture (`terminal_tool.rhai`)
